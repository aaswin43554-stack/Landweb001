# Custom Rules & Preferences

## Status / Daily Updates Format
Whenever the user requests "daily updates", "status updates", or summary reports of project changes, format the output as a concise, WhatsApp-friendly message using the following template:

```markdown
*📱 [Project/App Name] Improvements Update ([DD Month YYYY])*

*1. [Category Name]*
* *Before:* [Short description of previous state]
* *Now:* [Short description of current/improved state]

*2. [Category Name]*
* *Before:* [Short description of previous state]
* *Now:* [Short description of current/improved state]
```

Guidelines:
1. Use bold text markers (`*`) for headings and state prefixes.
2. Use relevant emojis in headers.
3. Keep descriptions punchy, short, and copy-paste ready for mobile messaging.
